# Claude Graphic, Motion & Slide Presentation Skills Store

Complete collection of **109+ Specialized Skills** for Claude, Claude Code, Cursor, Codex, and ZenDesign.

- **Embedded directly into the application binary**: Works automatically out-of-the-box on **Windows, macOS, and Linux**. End users never need to create manual folders, download extra packages, or configure paths.
- **Graphic & UI Design Skills**: 9 skills from Anthropic's official repository (Canvas Design, Algorithmic Art, Frontend Design, Themes, Brand Guidelines, GIFs, Presentations, Artifacts).
- **Motion & Video Skills**: 96 skills from the Claude Motion Skills Store (Explainers, Launch cuts, Data stories, Kinetic typography, Social reels, Bento grids, Particle effects).
- **Slide Presentation Skills**: Dedicated presentation engines (Dashi PPT, Marp Slides, Slide Maker, PPT Image-First, Boardroom Memo, Night Keynote, Studio Pitch, Chalk Classroom).

## Zero-Config In-App Integration

- **Embedded In Binary**: No manual folder creation or downloads required by users on any OS (Windows, macOS, Linux).
- **Auto-Matching**: ZenDesign automatically matches prompts in `slides`, `motion`, or `prototype` mode to the best skill and passes the full specification to your model API key.
