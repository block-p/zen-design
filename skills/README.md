# Claude Graphic & Motion Skills Store

Complete collection of **105 Graphic and Motion Skills** for Claude, Claude Code, Cursor, and ZenDesign.

- **Graphic & Design Skills**: 9 skills from Anthropic official skills directory (Canvas, Algorithmic Art, Frontend Design, Themes, Brand Guidelines, GIFs, Presentations, Artifacts).

Installed at: `~/.claude/skills/` (available to any Claude agent session).

## How to Use Any Skill with Claude

1. **Claude Code / Terminal**:
   ```bash
   # The skills are already linked in ~/.claude/skills/
   claude "Use the motion-director skill: a 20-second launch video, 16:9, for our new release"
   claude "Use the kinetic-type-title skill: make an 8s title card that says Ship faster, sleep better"
   claude "Use the canvas-design skill: create an interactive telemetry visualization"
   ```

2. **Inside ZenDesign**:
   ZenDesign agents automatically draw on the design systems, kinetic motion prompts, and graphic guidelines found in these skill packages.
