# Metric Spotlight

A dashboard counts up, then one tile takes the spotlight.

### Metric Spotlight

- Page: https://claude-motion.com/skills/metric-spotlight · Install: https://claude-motion.com/skills/metric-spotlight/install.md
- premium · Explainer · hyperframes · 16:9, 9:16, 1:1 · 7s
- Last checked: 2026-10-14

Three to six metric tiles count up with sparklines like a live dashboard. Then every tile but one blurs and dims, the chosen tile grows with an accent outline, and a badge explains the change.

Good fit: Highlighting one metric among several; Dashboard-style results updates.
Not for: Showing only one metric; Detailed charts.
Inputs: metrics, focus, note, trend (up | down), theme (ink | paper | electric | noir | sand), fontDisplay (serif | sans | grotesk | mono).

Example prompt: Use the metric-spotlight skill: metrics "Orders: 1,240 | AOV: $64 | Returns: 3.1% | Repeat rate: 38%", focus "Repeat rate", note "Up from 22%". Paper theme, 1:1.

Claude Motion prompt: Make a 7-second 16:9 dashboard scene for [who will watch, e.g. the growth team], playing [where, e.g. the weekly review]. Use only the six metrics I attach or list below; don't round or change any. Near-black background.

Six dark rounded tiles appear in a 3-by-2 grid, each counting up to its value while a thin sparkline draws along the bottom. Then every tile except the one I name blurs and fades, the named tile grows with an orange outline and an orange value. End frame: an orange pill with the takeaway pops onto its bottom edge, held for 1.5 seconds.

Six metrics: [names and values] (e.g. Visitors 48,210, Signups 3,904, Activation 61%, Trials 812, MRR $42.6k, Churn 2.1%)
Spotlight metric and takeaway: [e.g. Activation, "+18 pts since onboarding video"]
