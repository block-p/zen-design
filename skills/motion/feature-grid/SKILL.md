# Feature Grid

A bento grid that assembles, then spotlights each feature.

### Feature Grid

- premium · Launch · hyperframes · 16:9, 9:16, 1:1 · 10s
- Last checked: 2026-10-14

Four to six features in a bento grid with one hero tile and a big stat. Tiles assemble from a scatter, then lift and glint one by one. Perfect for feature overviews and landing-page videos.

Good fit: Feature overviews and landing-page videos; Products with four to six key features.
Not for: Explaining one feature in depth; Long feature lists.
Inputs: headline, features, stat, theme (ink | paper | electric | noir | sand), fontDisplay (serif | sans | grotesk | mono).

Example prompt: Use the feature-grid skill for our pricing page video: headline "Pro includes", stat "∞", features "Unlimited projects: No caps. | SSO: Okta, Google, Azure. | Audit log: Every change tracked. | Priority support: Under 1 hour."
